# Steel Wheel OCR Verification System | Industrial AI Studio

Automated wheel straightening, interactive multi-ROI selection, and OCR verification for industrial steel wheel manufacturing.

## Features
- **Live In-Browser Camera & Mobile Internal Camera**: Works directly in desktop and smartphone browsers.
- **YOLOv8 AI Powered**: Detects text characters and IST certification mark on curved/flat steel surfaces.
- **Interactive Multi-ROI Canvas**: Straightens skewed images and validates markings against master templates.
- **Siemens/Rockwell Grade UI**: Built for factory operators and quality inspectors.

## Running Locally
```bash
pip install -r requirements.txt
python app.py
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
